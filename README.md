# Blackbox Plugins

Official plugin repository for Blackbox - AI Tool Platform

## Available Plugins

### 🖼️ Remove Background
AI-powered background removal using BiRefNet, U2-Net, and more models.
- **Version**: 1.0.0
- **Size**: 4.3 MB
- **Models**: 15 different AI models for various use cases

### 🔍 Image Upscaler
Upscale images to higher resolution using AI or classical algorithms.
- **Version**: 1.0.0
- **Size**: Coming soon

### 📝 Extract Text (OCR)
Extract text from images using optical character recognition.
- **Version**: 1.0.0
- **Size**: Coming soon

## Installation

Plugins are automatically available in Blackbox's Tool Store.

1. Open Blackbox
2. Go to Tool Store
3. Browse or search for plugins
4. Click "Install"

## For Developers

This repository contains:
- `store.json` - Plugin catalog
- Plugin releases (ZIP files)

### Plugin Structure

Each plugin ZIP contains:
- `manifest.json` - Plugin metadata
- `processor.py` - Main processing logic
- `requirements.txt` - Python dependencies
- `assets/` - Icons and preview images
